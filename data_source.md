# Data Source

This project uses the **Online Retail** dataset from the UCI Machine Learning Repository.

The dataset contains transaction-level data from a UK-based online retailer and includes:

- Invoice number
- Stock code
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country

## Dataset Period

The transactions cover approximately:

**December 2010 – December 2011**

## Source

UCI Machine Learning Repository  
Online Retail Dataset

https://archive.ics.uci.edu/dataset/352/online+retail

## Usage

The dataset was used for educational and portfolio purposes to practice:

- Data cleaning
- Exploratory data analysis
- Sales analysis
- Customer analysis
- RFM segmentation
- Business insight development
